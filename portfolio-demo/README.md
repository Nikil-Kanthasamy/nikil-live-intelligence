# Nikil K — Career Dashboard

A responsive, static personal dashboard based on the LinkedIn profile information supplied.

## What's included
- Career overview and current role
- Experience timeline (Intern → Trainee → Business Analyst)
- Skills snapshot
- Career milestones
- Education placeholder for details not yet supplied

## Run locally
Open `index.html` in a web browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `nikil-career-dashboard`.
2. Upload `index.html` and this `README.md` to the repository's root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages section and will usually look like:
   `https://YOUR-USERNAME.github.io/nikil-career-dashboard/`

## Customize
- Edit the text directly in `index.html`.
- Update the skills bars if you want them to represent your own self-assessed proficiency. They are currently illustrative only.
- Replace the education placeholder once you add your school/college, degree and field of study.
- Change the title, colors or layout in the `<style>` section.

## Accuracy note
The dashboard intentionally does not invent project names, education details, certifications, quantified achievements or proficiency ratings.
